# Security policy

Do not publish vulnerabilities, signing keys, credentials, private documents, malicious samples, or unredacted personal information in a public issue.

Use GitHub's private vulnerability-reporting flow for `iiankehn/slate-r2-android` when available. Include the affected commit or release, Android version and device architecture, reproduction steps, impact, and the smallest safe proof of concept.

R2's security boundary includes local document persistence, recovery records, imported files, exported output, scoped content URIs, print/share flows, update verification, package signing, and parser resource limits.

Ordinary crashes, layout problems, and feature requests belong in GitHub Issues.
