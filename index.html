ONE ADAPTIVE WORKSPACE

Slate understands
the document.

Every file starts adaptive. Ordinary rich text stays a Note. Page layout, sections, headers, footers, structured tables, or page breaks promote it to Forge. Length alone never changes its type.

SLATE NOTES + WORD PROCESSING

One app.
Whatever you write.

The focused Notes library and the Forge ribbon, editing engine, page model, and responsive workspace now share one package, database, and monthly release.

  • Rich text, lists, checklists, links, images, tables, find, undo, and redo
  • Sections, custom pages, columns, headers, footers, pagination, PDF, and print
  • Search, folders, tags, favorites, archive, trash, autosave, and recovery history
  • `.slx`, `.slxf`, TXT, Markdown, DOCX, and verified native updates

THE SLATE STANDARD

Private by design.
Native by choice.

Slate stores writing locally, requires no account, and contains no advertising, telemetry, or background update polling. Import, export, sharing, printing, and update checks happen only when you ask.
