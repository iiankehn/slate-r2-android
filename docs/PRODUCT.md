# Slate R2 product brief

Slate R2 is a full word processor for Android across phone, tablet, foldable, and Googlebook Android form factors. It supports touch, stylus, mouse, trackpad, and keyboard as equal input paths.

## Product boundary

R2 and R1 are distinct products with independent monthly releases. R2 does not replace R1, share its package identity, or install over it. R1 remains the focused notes/document application; R2 owns advanced word-processing and broad-form-factor work.

## Principles

- Local documents remain authoritative and usable offline.
- Layout is deterministic across screen densities, print, and PDF.
- Editing commands operate on a versioned document model, not directly on UI widgets.
- Phone workflows remain complete while larger windows expose additional workspace chrome.
- Every interaction is reachable through touch and keyboard; stylus and pointer input add precision without becoming requirements.
- ARM64 and x86_64 are release requirements.
- File fidelity is measured and documented rather than implied.
- No account, ads, telemetry, or mandatory cloud service.

## Success criteria

R2 becomes releasable when it can create, edit, recover, import, export, print, and update representative multi-page documents reliably on every target form factor.
